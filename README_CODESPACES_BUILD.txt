HOZENIQ CMMS - GitHub Codespaces Android APK build

This package contains the Android WebView project with the mobile-responsive full CMMS app in app/src/main/assets/index.html, plus a GitHub Actions workflow.

After extracting this package into the ROOT of the existing GitHub repository (the folder containing .git), commit and push the files to the main branch. GitHub Actions will build the debug APK.

APK download: GitHub repository > Actions > Build HOZENIQ Android APK > latest successful run > Artifacts > HOZENIQ-CMMS-debug-APK.

The Android app package is com.dharmvir.cmms, minimum Android version is Android 8.0 (API 26), and app version is 6.1.

Note: This package does not replace the complete CMMS app with the separate mobile-screen preview HTML. It keeps the full functional CMMS application and its mobile-responsive layout.
